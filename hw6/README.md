# 行程（Process）與檔案相關系統呼叫 觀念整理

## 三個標準檔案描述子 (File Descriptors)

| 編號 | 名稱 | 對應裝置 | 說明 |
|------|------|----------|------|
| **0** | **stdin** (標準輸入) | 鍵盤 | 讀取輸入 |
| **1** | **stdout** (標準輸出) | 螢幕 | 輸出結果 |
| **2** | **stderr** (標準錯誤) | 螢幕 | 輸出錯誤訊息 |

這三個在你程式啟動時就自動打開了，不用自己 open。

---

## 系統呼叫一覽

| 系統呼叫 | 功能 | 標頭檔 |
|----------|------|--------|
| `fork()` | 複製目前行程，產生子行程 | `unistd.h` |
| `execvp()` | 把目前行程取代成另一個程式 | `unistd.h` |
| `open()` | 開啟檔案，回傳檔案描述子 | `fcntl.h` |
| `close()` | 關閉檔案描述子 | `unistd.h` |
| `read()` | 從檔案描述子讀資料 | `unistd.h` |
| `write()` | 寫資料到檔案描述子 | `unistd.h` |
| `dup2()` | 複製檔案描述子（可重新導向） | `unistd.h` |

---

## fork() — 建立新行程

```
fork() 回傳值：
  > 0 → 父行程，回傳值是子行程的 PID
  = 0 → 子行程
  < 0 → 失敗
```

fork 執行一次，但回傳兩次（父一次、子一次）。子行程會複製父行程的程式碼、變數、檔案描述子。

## execvp() — 執行程式

把當前行程的記憶體整個換掉，換成執行另一個程式。成功就不會回來，失敗才回傳 -1。

## open() / close() — 開啟/關閉檔案

```c
int fd = open("檔名", 旗標, 權限);
// 旗標：O_RDONLY, O_WRONLY, O_RDWR, O_CREAT, O_TRUNC 等
close(fd);
```

open 回傳一個整數（檔案描述子），通常從 3 開始（因為 0,1,2 已被佔用）。

## read() / write() — 讀寫資料

```c
ssize_t n = read(fd, buffer, 大小);
ssize_t m = write(fd, buffer, 大小);
```

回傳實際讀/寫到的位元組數，-1 表示錯誤。

## dup2(old_fd, new_fd) — 重新導向

把 `new_fd` 關掉，然後讓它指向 `old_fd` 同一個檔案。  
最常見用法：`dup2(fd, STDOUT_FILENO)` → 把原本要印到螢幕的內容導向到檔案。

## 核心觀念圖

```
           ╔═══════════════════╗
           ║   行程 (Process)   ║
           ╠═══════════════════╣
           ║  檔案描述子表格     ║
           ║  [0] → stdin      ║
           ║  [1] → stdout     ║
           ║  [2] → stderr      ║
           ║  [3] → 某個檔案    ║
           ║  [4] → 某個檔案    ║
           ╚═══════════════════╝
```

fork → 複製整張表格  
dup2 → 把某個索引指向另一個位置  
exec → 保留表格，換掉程式碼
