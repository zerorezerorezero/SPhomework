# NL 語言項目完成總結

## 🎯 項目概述

成功設計並實現了 **NL (Natural Language)** 編程語言及其完整解釋器。這是一門**貼近自然語言、易於理解**的編程語言。

## 📋 完成的功能

### 1. **語言設計** ✅
- ✅ 類似英語的直觀語法
- ✅ 強類型系統（運行時型態推論）
- ✅ 完整的 EBNF 語法規範
- ✅ 支持所有基本運算符: `+`, `-`, `*`, `/`, `%`, `>`, `<`, `>=`, `<=`, `==`, `!=`, `and`, `or`, `not`

### 2. **語言特性** ✅
- ✅ **變量聲明** - `let x = 10`
- ✅ **基本資料型態** - int, float, string, bool, nil, list
- ✅ **算術運算** - `+`, `-`, `*`, `/`, `%`
- ✅ **比較運算** - `>`, `<`, `>=`, `<=`, `==`, `!=`
- ✅ **邏輯運算** - `and`, `or`, `not`
- ✅ **條件語句** - `if...then...else...end`
- ✅ **While 循環** - `while...do...end`
- ✅ **For 循環** - `for...in...do...end`
- ✅ **函數定義與調用** - `func name(params) = ... end`
- ✅ **返回語句** - `return expr`
- ✅ **打印與輸入** - `print`, `read`
- ✅ **列表** - `[1, 2, 3]`
- ✅ **內置函數** - `len()`, `type()`, `int()`, `float()`, `string()`, `bool()`, `range()`

### 3. **編譯器/解釋器架構** ✅

完整的編譯管道：

```
源代碼 (.nl 文件)
    ↓
[詞法分析器 - Lexer]  → Token 流
    ↓
[語法分析器 - Parser]  → 抽象語法樹 (AST)
    ↓
[解釋器 - Interpreter]  → 執行結果
```

### 4. **核心模塊**

| 文件 | 功能 | 行數 |
|------|------|------|
| `lexer.py` | 詞法分析，將源代碼轉為 Token | ~350 |
| `parser.py` | 語法分析，構建 AST | ~450 |
| `interpreter.py` | 解釋執行 AST | ~350 |
| `runtime.py` | 運行時環境、內置函數 | ~250 |
| `ast_nodes.py` | AST 節點定義 | ~150 |
| `main.py` | 主程序入口、交互式 REPL | ~200 |

**總計：約 1,750 行 Python 代碼**

## 🎨 語言範例

### 基本示例
```nl
let x = 10
let y = "Hello"
print x, y
```

### 函數示例
```nl
func fibonacci(n) =
    if n <= 1 then
        return n
    else
        return fibonacci(n - 1) + fibonacci(n - 2)
    end
end

print fibonacci(10)
```

### 循環示例
```nl
let sum = 0
let i = 1
while i <= 100 do
    sum = sum + i
    i = i + 1
end
print "Sum 1-100:", sum
```
